# Central de Estudos Bíblicos

Primeira versão estática para preparar aulas da Escola Bíblica Dominical, pregações (tópicas, expositivas ou combinadas) e estudos bíblicos pessoais.

## Como testar

Abra `index.html` no navegador. Os materiais são salvos no armazenamento local do navegador (`localStorage`). Exporte um backup JSON para preservar ou transferir seus materiais.

## Publicar gratuitamente no GitHub Pages

1. Envie `index.html` e `README.md` para a raiz do repositório `wllmslv10/central-estudos-biblicos`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`, depois salve.
4. Aguarde a publicação. O endereço esperado é `https://wllmslv10.github.io/central-estudos-biblicos/`.

## Limitações desta versão

- Não tem IA integrada, login, banco de dados ou sincronização entre dispositivos.
- Os materiais ficam no navegador onde foram criados; use backup JSON para transferi-los.
- Consulte sua Bíblia para verificar o texto integral, o contexto e as referências.
