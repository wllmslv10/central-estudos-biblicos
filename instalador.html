Instalador para celular, tablet e computador

📲 Instalar aplicativo

Use este botão para instalar a Central como aplicativo quando seu navegador oferecer suporte. A instalação mantém o endereço oficial e abre a Central em uma janela própria.

Abrir a Central
Verificando as opções de instalação deste navegador…

O navegador sempre pedirá sua confirmação. Esta página não instala programas silenciosamente nem baixa APK ou EXE.

📱 Android — celular ou tablet

  1. Abra esta página no Google Chrome.
  2. Toque em Instalar aplicativo quando o botão estiver disponível.
  3. Se o botão não abrir a confirmação, toque no menu ⋮ do Chrome e procure Instalar aplicativo ou Adicionar à tela inicial.
  4. Confirme e procure o ícone da Central na tela inicial ou na lista de aplicativos.

💻 Windows — computador ou notebook

  1. Abra esta página no Google Chrome ou Microsoft Edge.
  2. Use o botão de instalação acima, se disponível, ou procure o ícone de instalação na barra de endereço.
  3. No Edge, também pode usar o menu Aplicativos → Instalar este site como aplicativo.
  4. Confirme a instalação e abra pelo menu Iniciar.

🍎 iPhone e iPad

  1. Abra o endereço oficial no Safari.
  2. Toque em Compartilhar.
  3. Escolha Adicionar à Tela de Início e confirme.

No iPhone/iPad, o botão personalizado de instalação não é disponibilizado por todos os navegadores; use o procedimento acima.

ℹ️ Sobre seus materiais

A Central é um aplicativo web (PWA), não um instalador nativo APK/EXE. As anotações salvas ficam no armazenamento do navegador daquele dispositivo e não são sincronizadas automaticamente. Na biblioteca da Central, use Exportar backup para guardar ou transferir seus materiais.
